# Runeterra POI icons

Downloaded from https://map.leagueoflegends.com/assets/images/ (Explore Runeterra, © Riot Games,
fan use only). Mapping used in src/features/mapa/pois.ts:

- regions/{slug}.png (+ -hover): region crests (iconType *Crest). piltover-zaun is 128x256.
- pins/capital.png (+ -hover): starCircle landmarks, Piltover / Zaun (doubleTop/doubleBottom).
- pins/town-med.png (+ -hover): city.
- pins/town-sml.png: dot (towns; no official hover).
- pins/capital-frame.png, landmark(-hover).png: downloaded but unused (doubleBackground / landmarkCircle).
